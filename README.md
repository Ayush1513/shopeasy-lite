# ShopEasy Lite

A lightweight shopping cart application built using Node.js.

## Features
- Add products to cart
- Calculate cart total
- Validate product prices and quantities
- HTTP server using Node.js
- Automated tests using Node.js test runner

## Project Structure
shopeasy-lite/
├── src/
│   ├── cart.js
│   └── server.js
├── test/
│   └── cart.test.js
├── .gitignore
├── package.json
└── README.md

## Requirements
- Node.js
- npm
- Git

## Run the Application
node src/server.js

Open http://localhost:3000 in your browser.

## Run Tests
node --test
